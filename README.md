# 📚 Resumidor de Documentos y Generador de Exámenes v2.0 

Aplicación web construida en **Python + Streamlit** que analiza documentos académicos (`.docx`, `.pdf`, `.pptx`, `.txt`), genera resúmenes estructurados proporcionales y crea bancos de preguntas de examenes


## 🚀 Despliegue en Streamlit Cloud
1. Sube estos archivos a tu repositorio de GitHub (rama `main`).
2. En [share.streamlit.io](https://share.streamlit.io/), selecciona tu repositorio, rama `main` y archivo principal `app.py`.
